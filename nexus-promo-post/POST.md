## 三个核心功能

### 1. 继任风险分析：谁走了公司会瘫痪，自动标出来

每个部门按「负责人是否在 + 有没有副手候选」自动分级，整张图红黄绿一目了然：

- **红色 · 高风险**：关键岗位空缺，部门里没人带管理头衔，出了事没人拍板
- **黄色 · 中风险**：继任断层，一个人在扛（一休假就停），或负责人没有副手
- **绿色 · 低风险**：继任梯队健全，负责人在、副手备好了

不是拍脑袋，是纯数据驱动：后端用管理头衔正则分级（总裁 > 总监 > 经理/主管 > 组长/HRBP），同步完通讯录三秒自动出结果。

### 2. AI 一键总结：三秒产出一份组织健康报告

风险分析只是一堆色块，点一下 **AI 分析**，自动拼成一份可汇报的报告：

- 整体评估：高/中/低风险部门各几个，先处理什么
- 逐部门行动建议：哪个部门要立刻指定临时负责人、哪个要启动招聘
- 低风险部门的标杆做法，一并列给你

从点击到成稿，三秒。

### 3. 万级节点的图谱，还能拖着玩

- **双视图**：组织树（垂直层级）⇄ 关系图（力导向布局），随时切换
- **搜索即定位**：输名字/部门，下拉命中，点击直接聚焦到图上节点
- **节点可拖拽**：关系图模式下按住节点直接拖，连线自动跟随，布局你说了算
- **万级也流畅**：Canvas + LOD 三级渲染（全量鹰眼 → 视口 → 子图），上万节点保持 60 FPS

## 深融合钉钉

- **免登即用**：在钉钉工作台点开，就是你的组织，不用注册
- **点击员工节点 → 一键发起单聊**，不用回通讯录找人
- **一键打开钉钉审批中心**，从图谱直达流程
- **通讯录实时同步**：部门树 + 员工，点一下「同步钉钉通讯录」就到图上

## 技术栈（不是玩具）

| 层 | 技术 |
| --- | --- |
| 前端 | React + Vite，全部交互收敛在一个 GraphApp.jsx（树布局 / Canvas LOD / 搜索 / 拖拽 / 风险面板） |
| 后端 | 3 个 Node 微服务：gateway 反向代理 / knowledge 数据层（SQLite）/ dingtalk 对接 |
| 钉钉 | 免登 authCode→JWT、通讯录 BFS+分页同步、JSAPI（发起单聊 / 打开应用） |

原本是 16 个模块的"数字中枢"，独立开发者砍到只留最深的一个功能做透——关系图谱。

## 怎么用起来：获取源码 → 发布到钉钉酷应用

### 第 1 步：获取源码

```bash
git clone https://github.com/WangYuecheng1106/nexus-digital-hub.git
cd nexus-digital-hub
npm install
```

### 第 2 步：本地一键起服务（先验证）

确认 Node.js ≥ 22 后执行：

```bash
npm run dev
```

看到 `Local: http://localhost:5173/` 即成功，浏览器打开即可体验（首次打开自动载入演示数据，无需注册）。验证项：

- 组织树/关系图切换 → 各部门与人员节点正常
- 「继任风险」→ 部门按红/黄/绿三态着色，右侧列出分析与候选副手
- 「AI 分析」→ 三秒生成整体评估 + 行动建议报告
- 「关系图」下按住节点 → 可拖拽，连线实时跟随

### 第 3 步：部署到可公网访问的服务器

1. 构建前端产物：`npm run build:client`（产物在 `client/dist`）
2. 用 nginx 托管 `client/dist`，并把 `/api/*` 反向代理到后端网关 8080 端口（详见 readme「生产部署」章节）
3. 确保你的域名解析到服务器；**钉钉要求 HTTPS**，请为域名配置有效证书（腾讯云免费证书 / Let's Encrypt 均可）

### 第 4 步：在钉钉开发者后台把它发布成酷应用

1. 登录 [钉钉开发者后台](https://open-dev.dingtalk.com/) → **应用开发 → 企业内部应用 → 创建应用**，应用类型选择 **酷应用**
2. 在 **应用能力** 中添加 **网页应用(H5)**，把部署后的 HTTPS 地址填为「应用首页地址」（移动端 & PC 端）
3. 在 **权限管理** 申请并等待通过：「通讯录部门信息读权限」+「通讯录部门成员读权限」
4. 把 **凭证与基础信息** 里的 Client ID(AppKey) / Client Secret(AppSecret) / CorpId / AgentId 填到应用页面顶栏「接入钉钉」弹窗中
5. 点「同步钉钉通讯录」，真实组织即刻上图，继任风险自动出结果
6. 回到钉钉后台 → **版本管理与发布 → 提交发布**，审核通过后员工就能在钉钉工作台 / 群内直接打开使用

### 第 5 步：使用

- 员工：钉钉工作台点击「Nexus 关系图谱」，免登即用，点人即可发起单聊
- 管理员 / HR：进「继任风险」看全公司关键岗位的健康度，一键 AI 生成汇报
