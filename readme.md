# 自主迭代工作法（核心，必须严格执行）

## 总原则

你必须以"计划→执行→自检→迭代"的循环驱动整个项目，而不是线性地做一遍就结束。
禁止行为：写完即停、用"后续可扩展"搪塞未完成功能、以"框架已搭好"为由跳过真实实现。

## Loop Engineering 分阶段推进

不要一次铺开所有功能，必须按以下阶段增量交付，每阶段通过验证后再推进下一阶段：

- **阶段一（地基）**：搭好网关 + auth 服务，跑通登录→签发 JWT→权限校验完整链路，确认身份基座可用。
- **阶段二（核心通讯）**：加 im 服务，跑通消息发送→接收→实时推送→已读回执→消息撤回，确认通讯链路可用。
- **阶段三（音视频）**：加 meeting 服务，跑通一对一通话→多人会议→屏幕共享→会议录制，确认音视频链路可用。
- **阶段四（评审重点）**：加 knowledge 服务与关系图谱前端，跑通关系图谱加载→缩放→拖拽→双击聚焦子图，用万级节点压测确认不卡顿。
- **阶段五（协作套件）**：加 document + workflow + calendar + drive，跑通文档协作→流程审批→日程管理→文件共享。
- **阶段六（管理模块）**：加 project + attendance + contacts，跑通任务管理→考勤打卡→通讯录。
- **阶段七（平台整合）**：加 integration + ai + analytics + portal + forum + notification，整合为统一工作入口门户，前端整合所有模块为可演示页面。
- **阶段八（端到端审视）**：对整体做一轮端到端自检，发现退化或短板则回头加固。

每完成一个阶段，必须进入下方"自动化验证"流程，通过后才推进下一阶段。

# 自动化验证机制（必须使用，这是自主迭代的执行手段）

你的"自检"不能停留在主观判断，必须用工具做真实验证：

## 1. Playwright 自动化端到端测试

用本机 Playwright（Python 版已安装，chromium 已就绪）编写真实测试脚本，覆盖关键链路：

- **登录流程**：输入凭证 → 断言 JWT 签发成功、响应包含 token
- **权限校验**：用不同角色访问受限资源 → 断言 403/200 符合预期
- **IM 通讯**：发送消息 → 断言消息入库、对端收到推送、已读回执正确更新
- **视频会议**：发起会议 → 加入会议 → 断言媒体流建立、屏幕共享可切换
- **关系图谱**：加载关系图谱 → 模拟缩放/拖拽/双击 → 断言视口内节点数随缩放变化、聚焦子图正确渲染

- **文档协作**：创建文档 → 多用户同时编辑 → 断言内容同步无冲突
- **流程审批**：发起审批 → 逐级审批 → 断言流程状态流转正确

测试脚本存 `./tests/e2e/`，执行后抓取 console 报错，有报错立即修复并重跑。

## 三、核心模块设计

### 3.1 统一身份认证与权限管理（nexus-auth）

**对标产品**：钉钉管理后台、WeLink 身份管理

#### 认证体系

- **认证协议**：OAuth 2.0 + OpenID Connect，兼容 SAML 2.0
- **令牌机制**：JWT（30 分钟短效）+ Refresh Token（7 天长效），支持令牌撤销与黑名单
- **多因素认证（MFA）**：TOTP（Google Authenticator 兼容）、短信验证码、邮箱验证码、生物识别（指纹/Face ID via Electron native API）
- **扫码登录**：手机扫码登录桌面端（生成临时二维码 → 轮询确认状态 → 签发 JWT）

#### 目录对接

- LDAP/Active Directory 同步（增量同步 + 全量同步）
- 企业微信、钉钉、飞书组织架构导入
- SCIM 2.0 协议支持（自动化用户生命周期管理）
- 用户入/离/调岗：入职开通账号分配权限 → 离职冻结账号回收权限

#### 权限模型

- **RBAC + ABAC 混合**，四层分离：
  - 岗位层：定义组织中的岗位（如"销售经理""财务主管"）
  - 角色层：定义系统角色（如"管理员""普通员工""审计员"）
  - 数据范围层：控制可见数据边界（本人/本部门/本部门及下属部门/全部）
  - 操作权限层：控制具体操作（查看/新增/编辑/删除/导出/审批）
- **细粒度数据权限**：
  - 行级权限：基于数据行的属性过滤（如只能看自己创建的订单）
  - 列级权限：基于字段级别的可见性控制（如隐藏薪资字段）
- **动态授权**：基于上下文的运行时权限判断（如"工作时间才能导出""仅本部门数据可编辑"）
- **权限审计**：记录所有权限变更操作，支持权限追溯与合规审查

#### 实现要求

- 密码存储使用 BCrypt（cost ≥ 12），禁止明文存储
- 登录失败锁定策略（连续 5 次失败锁定 15 分钟）
- JWT 签名使用 RS256（非对称加密），公钥分发给 gateway 校验
- 所有认证相关接口强制 HTTPS

### 3.2 即时通讯（nexus-im）

**对标产品**：钉钉 IM、WhatsApp、WeLink 消息

这是使用频率最高的模块，消息投递的可靠性、实时性和丰富度直接决定产品体验。
必须达到"消息不丢、不重、不乱序"的工业级标准。

#### 会话管理

- **单聊**：一对一私密对话
- **群聊**：支持 500+ 人群组
  - 群组角色：群主（唯一）、管理员（群主任命）、普通成员
  - 群组操作：创建/解散、邀请加入、移除成员、转让群主、设置管理员
  - 群公告：群主/管理员可发布，置顶显示，新成员入群自动展示
  - 群禁言：全员禁言/指定成员禁言（可设时长）
  - 群昵称：成员可设置群内昵称
- **会话列表**：
  - 最近会话列表（按最后消息时间排序）
  - 未读消息数红点徽标
  - 会话置顶（多会话按置顶顺序排列）
  - 消息免打扰（静音通知但不影响未读数）
  - 会话删除与恢复
  - 草稿保留（切换会话时保存未发送内容）

#### 消息类型（必须全部实现）

1. **文本消息**：支持富文本（加粗、斜体、删除线、链接、引用块、行内代码、代码块）
2. **图片消息**：支持多图发送、原图/缩略图、点击全屏查看、手势缩放、左右滑动浏览
3. **语音消息**：录音（长按说话/点击录音）、播放（进度条拖拽）、语音波形显示、最大时长 5 分钟
4. **视频消息**：录制/选择视频发送、压缩转码、在线播放、封面缩略图
5. **文件消息**：支持所有格式（doc/xls/ppt/pdf/zip/rar/exe 等），大文件分片上传（>50MB 自动分片）、断点续传、下载进度显示
6. **位置消息**：集成地图 SDK，发送当前位置/选择位置，点击打开地图导航
7. **名片消息**：分享联系人名片，点击可发起会话或查看资料
8. **投票消息**：群内发起投票（单选/多选/匿名投票），实时统计结果
9. **合并转发消息**：多条消息合并为一条转发消息，点击展开查看全部内容
10. **DING 消息**：重要消息强提醒（类似钉钉 DING），接收方收到电话/短信/应用内弹窗三重提醒，支持查看已读/未读名单

#### 消息交互

- **已读/未读回执**：
  - 单聊：显示"已读"/"未读"状态
  - 群聊：显示已读人数（点击查看已读/未读人员列表）
  - 阅后即焚模式（可选，消息查看后自动删除）
- **消息撤回**：2 分钟内可撤回，撤回后双方均可见"XX 撤回了一条消息"
- **消息回复**：引用某条消息进行回复，显示引用内容与回复关系
- **@提及**：
  - @指定成员（输入@后弹出成员选择列表）
  - @所有人（仅群主/管理员可用，普通成员受权限控制）
  - 被@的消息高亮标记，通知强提醒
- **消息转发**：单条转发/多条合并转发，可转发到会话或收藏
- **消息收藏**：收藏重要消息，支持分类管理与全文搜索
- **消息复制/粘贴**：复制文本内容，支持跨应用粘贴
- **消息多选**：进入多选模式，批量转发/删除/收藏
- **表情系统**：
  - Unicode 表情（😀🎉👍）
  - 自定义表情包（支持上传与管理）
  - GIF 动图搜索与发送
- **消息撤回与删除的区别**：撤回（对方不可见，2 分钟内）/ 删除（仅自己端删除，对方仍可见）

#### 消息搜索

- **全局搜索**：搜索范围包含联系人、消息内容、文件、链接
- **搜索条件**：按发送人、消息类型、时间范围、关键词组合筛选
- **搜索结果**：高亮匹配关键词，点击跳转到对应消息上下文
- **搜索性能**：10 万条消息内搜索响应 < 200ms（使用 Elasticsearch 或倒排索引）

#### 消息漫游与多端同步

- **云端漫游**：消息存储在服务器，新设备登录后自动拉取历史消息（默认 6 个月）
- **多端同步**：已读状态、会话列表、草稿在多设备间实时同步
- **离线消息**：用户离线时消息存储在服务器，上线后自动推送
- **消息顺序保证**：单会话内消息严格有序（基于服务端时间戳 + 序列号）

#### 在线状态

- 状态类型：在线/离线/忙碌/离开/勿扰/隐身
- 自定义状态文案（如"会议中，请稍后联系"）
- 状态自动切换（长时间无操作 → 离开，关闭应用 → 离线）
- 联系人列表实时显示在线状态

#### 安全

- 传输层加密：全链路 TLS 1.3
- 存储层加密：消息内容 AES-256 加密存储（可选开启）
- 敏感词过滤：消息发送前进行敏感词检测（支持正则匹配、拼音检测），命中则拦截或打码
- 截屏提醒：敏感会话中截屏时向对方发送提醒通知
- 防转发：标记为机密的消息禁止转发、复制、截屏

#### 技术要求

- WebSocket 长连接，心跳保活（30 秒），断线自动重连（指数退避）
- 消息投递保证：At Least Once，客户端去重（基于消息 ID）
- 消息 ID：Snowflake 雪花算法生成，保证全局唯一且趋势递增
- 消息存储：按会话分表，使用时序数据库（如 InfluxDB）或 MySQL 分表
- 推送通道：WebSocket（在线）+ Web Push / Electron 系统通知（离线）
- 消息分片上传：大文件 > 50MB 自动分片（每片 5MB），支持断点续传
- 并发优化：群消息使用写扩散（写多读少场景）或读扩散（读多写少场景）策略

### 3.3 视频会议（nexus-meeting）

**对标产品**：钉钉会议、WhatsApp 视频通话、WeLink 会议

这是企业协作的核心能力，必须做到"低延迟、高清晰、弱网可用"。
音视频质量与稳定性直接决定会议体验，任何卡顿、回声、啸叫都是不可接受的。

#### 会议创建与管理

- **预约会议**：设置会议主题、开始时间、预计时长、参会人员、会议密码、会议描述
- **即时会议**：一键发起即时会议，自动生成会议号与会议链接
- **周期性会议**：每天/每周/每月重复，支持自定义重复规则
- **会议邀请**：
  - 通过 IM 消息发送会议链接
  - 通过邮件发送会议邀请
  - 通过日历日程自动创建会议事件
  - 会议链接一键复制分享
- **等候室**：参会者加入后进入等候室，主持人审批后方可进入会议
- **会议号体系**：9 位数字会议号 + 可选会议密码，支持通过会议号加入

#### 音视频通话

- **一对一音视频通话**：从 IM 单聊中一键发起，支持音频通话与视频通话切换
- **多人视频会议**：
  - 支持 100+ 人同时参会（SFU 架构）
  - 视频布局：画廊模式（九宫格）、演讲者模式（大画面 + 小画面列表）、侧边栏模式
  - 自适应布局：参会人数变化时自动调整画面大小与排列
  - 单人全屏：双击某人画面全屏查看
- **音频通话**：纯音频会议模式（节省带宽）
- **视频质量**：
  - 默认 720P，网络良好时自动升级 1080P
  - 带宽不足时自动降级（720P → 480P → 360P → 音频模式）
  - 自适应码率（Simulcast 多分辨率编码）
- **音频处理**：
  - 回声消除（AEC）：防止扬声器声音回传麦克风
  - 噪声抑制（NS）：过滤键盘敲击、风扇等环境噪声
  - 自动增益控制（AGC）：自动调节音量到舒适范围
  - 静音/取消静音：快捷键支持，主持人可强制静音参会者
- **网络质量指示**：实时显示网络质量（优秀/良好/一般/差），弱网时自动降级

#### 屏幕共享

- **共享类型**：
  - 共享整个屏幕（包含所有窗口与桌面）
  - 共享单个应用窗口（仅共享指定窗口内容）
  - 共享浏览器标签页
- **共享批注**：共享时可在屏幕上绘制标注（画笔、箭头、文字、高亮），支持多人同时批注
- **远程控制**：共享者可授权参会者远程操作其桌面（需二次确认授权）
- **共享音频**：共享屏幕时可选择同时共享系统音频（播放视频/音频时对方可听到）
- **共享切换**：会议中随时切换共享内容源

#### 会议录制

- **云端录制**：录制文件存储在服务器，不占用本地空间
- **录制控制**：主持人手动开始/暂停/停止录制，也可设置自动录制
- **录制内容**：同时录制屏幕共享 + 音频，生成 WebM/MP4 文件
- **录制管理**：录制文件列表（会议主题/时间/时长/大小），支持下载、分享、删除
- **AI 会议纪要**：录制结束后自动转文字（语音识别），提取关键信息（讨论议题、决议事项、待办任务、责任人），生成结构化会议纪要

#### 会议互动

- **举手发言**：参会者点击举手按钮，主持人端显示举手列表，可依次允许发言
- **会议内聊天**：文字聊天面板，支持发送文字/图片/文件，可选择"发给所有人"或"私聊某人"
- **实时字幕**：AI 语音转文字，实时显示在画面底部（支持中英文）
- **实时翻译**：发言内容实时翻译为参会者选择的语言（支持中/英/日/韩等常见语言互译）
- **互动白板**：多人实时协同绘制白板（画笔/形状/文字/橡皮擦/撤销重做），白板内容可保存
- **投票/问卷**：会议中发起投票，实时统计结果并展示

#### 会议安全

- **会议密码**：加入会议需输入密码（主持人设置）
- **会议锁**：锁定后新参会者无法加入（需主持人解锁）
- **移除参会者**：主持人可移除扰乱会议的人员
- **权限控制**：仅主持人/联席主持人可共享屏幕、管理录制、管理参会者
- **加密传输**：SRTP 加密音视频流，DTLS 加密信令

#### 虚拟背景

- **预设背景**：提供 6+ 种预设背景图片（办公室/客厅/书房/纯色/虚化等）
- **自定义背景**：用户上传图片作为虚拟背景
- **背景虚化**：摄像头画面背景虚化效果（人像清晰、背景模糊）
- **无背景**：关闭虚拟背景，使用真实摄像头画面

#### 会议室预定（联动 calendar 服务）

- **物理会议室管理**：会议室列表（名称/容量/设备/位置），可编辑会议室信息
- **预定与冲突检测**：选择时间段预定会议室，自动检测时间冲突
- **会议室状态看板**：可视化展示各会议室当天预定状态
- **扫码签到**：会议开始前 10 分钟到场扫码签到，超时未签到自动释放

#### 技术要求

- **WebRTC**：P2P（一对一）+ SFU（多人）混合架构
- **SFU 媒体服务器**：使用 mediasoup 或 LiveKit（性能优先，Node.js/Go 生态集成方便）
- **NAT 穿透**：部署 TURN/STUN 服务器（coturn），确保复杂网络环境下可连通
- **编解码**：视频 H.264/VP8/VP9，音频 Opus
- **Simulcast**：发送多分辨率编码流，SFU 按接收端带宽选择转发
- **信令服务器**：WebSocket 实现 SDP 交换与 ICE 协商
- **弱网优化**：FEC 前向纠错 + 抖动缓冲 + 丢包重传（NACK/PLI）
- **Electron 桌面端**：使用 `desktopCapturer` API 获取屏幕共享源

### 3.8 关系图谱可视化（nexus-knowledge）

**关键功能，评审重点，必须重点实现**

类似 Obsidian 的关系图谱，把部门关系、员工关系、处理事项构建为关系网络。
真实企业节点数可达 10 万+，纯 D3.js 会直接卡死，必须采用专家级渲染分层架构：

#### 渲染分层架构

- **L0（鹰眼/缩略图）**：Canvas 2D 绘制全部节点（只画点不画文字），提供全局概览，显示当前视口范围框
- **L1（当前视口）**：按缩放层级动态请求后端，仅拉取视口内的节点与边，Canvas 2D 绘制节点与连线
- **L2（聚焦交互）**：双击节点用 WebGL（Three.js/Pixi.js）或 G6 5.0（GPU 加速）绘制高亮子图，显示节点详细信息与关系标签

此模块必须做到真实可交互、万级节点下不卡顿（FPS ≥ 30）。

#### 交互操作

- **加载**：初始加载时从后端获取全量节点位置坐标（预计算布局），L0 一次性渲染全部节点
- **缩放**：滚轮/手势缩放，缩放级别变化时动态请求 L1 层数据，视口外节点不渲染
- **平移/拖拽**：拖拽画布平移视图，拖拽节点调整位置（仅 L2 层可拖拽单节点）
- **双击聚焦**：双击节点 → 后端返回该节点的 1-3 度关系子图 → L2 层 WebGL 高亮渲染子图，其余节点淡化
- **节点搜索**：输入关键词定位节点，自动缩放并居中显示
- **节点筛选**：按节点类型（部门/员工/事项/文档）、关系类型筛选显示
- **节点信息面板**：点击节点显示侧边信息面板（节点属性、关联关系列表、关联节点跳转）

#### 关系图谱数据模型

- 节点类型：部门、员工、角色、项目、任务、文档、审批流程、会议
- 边类型：隶属（员工→部门）、汇报（员工→上级）、参与（员工→项目）、负责（员工→任务）、
创建（员工→文档）、发起（员工→审批）、出席（员工→会议）
- 边属性：关系强度（交互频次）、关系时间（最近交互时间）

#### 后端图数据库

- 使用 Neo4j 或 NebulaGraph 存储图数据
- 视口查询接口：根据缩放级别 + 视口边界框返回节点与边（分页 + LOD 策略）
- 子图查询接口：给定节点 ID + 深度，返回邻居子图
- 预计算布局：使用力导向算法（ForceAtlas2）预计算节点位置坐标，缓存到 Redis

#### 压测要求

- 注入 10000+ 节点 + 50000+ 边
- 初始加载 < 3 秒
- 缩放/拖拽/平移 FPS ≥ 30
- 双击聚焦子图加载 < 1 秒
- 内存占用稳定无泄漏（连续操作 10 分钟内存波动 < 5%）

### 3.10 考勤管理（nexus-attendance）

**对标产品**：钉钉考勤

#### 打卡方式

- **GPS 定位打卡**：获取当前位置，校验是否在考勤范围内（公司坐标 + 半径，支持多考勤点）
- **WiFi 打卡**：连接指定 WiFi SSID 后打卡（防止远程代打卡）
- **人脸识别打卡**：摄像头拍照 + 人脸比对（防止他人代打卡）
- **外勤打卡**：不在考勤范围内时提交外勤打卡（附位置 + 备注 + 照片）

#### 排班管理

- **固定班制**：设定每天上下班时间（如 09:00-18:00），支持多个班次
- **排班制**：按周/月排班，每人每天可分配不同班次，可视化排班日历
- **弹性工制**：设定弹性时段（如 08:30-10:00 任意打卡，满足 8 小时即可）
- **轮班管理**：早班/中班/夜班轮换排班

#### 考勤规则

- 打卡时间范围（上班前 1 小时至下班后 1 小时可打卡）
- 迟到/早退判定规则（超过规定时间 X 分钟算迟到/早退）
- 旷工判定（全天未打卡且无请假记录算旷工）
- 加班规则（下班后继续工作 X 小时以上算加班，需主管审批）
- 补卡规则（忘打卡可申请补卡，需主管审批）

#### 请假/调休/加班

- 请假类型：年假/事假/病假/调休/婚假/产假/陪产假/丧假（可自定义类型）
- 请假申请 → 审批流程联动（走 workflow 审批）
- 年假额度管理（按工龄自动计算年假天数，支持结转规则）
- 调休额度管理（加班转调休，调休使用记录）
- 假期日历（可视化展示各部门请假情况，便于排班参考）

#### 统计报表

- **个人考勤月报**：出勤天数/迟到次数/早退次数/请假天数/加班时长/旷工天数
- **部门考勤统计**：汇总部门全员考勤数据，支持按月/季/年统计
- **异常考勤提醒**：迟到/早退/未打卡自动提醒员工与主管

- 多语言文档摘要

- 搜索建议与联想

- IM 消息实时翻译（收到外语消息自动翻译为用户语言，原文与译文并列显示）

- 会议实时翻译（参会者选择各自语言，发言内容实时翻译显示）

#### 智能提醒

- 重要消息识别（AI 判断消息重要性，自动标记并优先提醒）
- 待办自动提取（从对话/文档中自动识别待办事项并提醒创建任务）

#### 实现要求

- 接入大语言模型 API（如 OpenAI GPT / Claude / 国产模型），支持配置切换
- RAG 架构：文档向量化（Embedding）→ 向量数据库存储（Milvus/Chroma）→ 语义检索 → 上下文增强生成
- ASR 语音识别：接入 Whisper 或国产语音识别 API
- 所有 AI 功能需标注"AI 生成"标识，提醒用户审阅

## 五、安全与合规

### 数据安全

- **传输加密**：全链路 TLS 1.3
- **存储加密**：敏感数据 AES-256 加密存储（密码/手机号/身份证号等）
- **密钥管理**：不硬编码密钥，使用环境变量或密钥管理服务
- **数据备份**：定期自动备份，支持恢复

### 审计日志

- 记录所有关键操作：登录/权限变更/数据导出/文件删除/审批操作
- 日志不可篡改（追加写入 + 哈希链校验）
- 日志保留期限 ≥ 180 天
- 日志查询与导出（管理员可按时间/操作人/操作类型筛选）

### 防泄密

- **水印**：文档/截图自动添加用户水印（姓名 + 工号 + 时间）
- **防截屏**：敏感页面截屏检测与提醒
- **防转发**：机密消息禁止转发/复制/截屏
- **下载控制**：文件下载需权限校验 + 审计记录

### 合规要求

- 遵循《个人信息保护法》《数据安全法》要求
- 用户数据采集需明示告知并获得同意
- 支持用户数据导出与删除（数据可携带权与被遗忘权）
- 最小权限原则：各服务仅访问其必需的数据
